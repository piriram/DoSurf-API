## 1. 임계값이 이틀 연속 틀렸다

어제 `snap_distance_km` 를 폐기하고 **인접 겹침 1km** 로 정했다. 구현하면서
32곳 전부의 같은 지역 최소 이웃거리를 재 봤다.

```
정상 최솟값   사천진↔사천 2.12km · 인구↔기사문 2.20km · 월정↔김녕 3.36km
옛 오류값     남애3리 0.58km · 물치 1.32km
현재 최솟값   월포↔영덕 부흥 0.85km   ← 이게 문제였다
```

**1km 는 물치(1.32km)를 놓치고 월포↔부흥(0.85km)을 오탐한다.**

정상 최솟값이 2.12km 이므로 **2km** 로 잡으면 옛 오류 둘을 모두 잡고 정상값과
겹치지 않는다. 그리고 2km 로 잡았을 때 현재 좌표에서 걸린 것이 딱 하나였다 —
월포↔부흥. **오탐이 아니라 진짜 오류였다.**

> **교훈.** 임계값을 문서에서 정하고 구현하러 가지 말 것. 이틀 연속 실측이
> 문서 안을 반박했다. 후보 임계값을 정하면 **정상값 분포를 먼저 재고** 그
> 사이가 갈리는지 본다.

## 2. 「좌표 순서 역전」은 성립하지 않는다

어제 설계의 세 신호 중 하나였다. 구현하려니 판정할 기준이 없다.

`locations.json` 에 **지리적 정렬 순서가 없다.** `beach_id` 는 등록 순서이고
(양양 1001~1006 = 죽도·인구·기사문·갯마을·남애3리·물치, 위도로는 순서가
뒤섞여 있다), 위도로 정렬하면 **어떤 배열이든 단조가 된다.**

물치를 잡으려면 "물치는 양양 최북단이어야 한다"는 외부 지식이 필요한데
그건 좌표 파일에 없다. **겹침 신호(1.32km)가 물치를 잡으므로 공백은 아니다.**

구현하지 않은 이유를 코드 주석과 `AGENTS.md` 에 남겼다 — 다음 세션이 "빠진
신호"로 보고 다시 시도하지 않게.

## 3. 영덕 부흥이 두 번 틀렸다

**어제(09-27) 내륙 좌표를 고칠 때 동쪽(해안) 대신 남쪽으로 옮겼다.**

| 시점 | 좌표 | 문제 |
|---|---|---|
| 원래 (2025-03) | 36.4171, 129.3704 | 해안에서 6km 내륙 · 고도 40m · 바다 방위 0/36 |
| 09-27 수정 | **36.195**, 129.373 | **24.7km 남쪽** — 월포에서 0.85km |
| 09-29 수정 | **36.2885, 129.3765** | 고도 0m · 육지 5/8 · 스웰창 170° |

부흥리는 **영덕군 남정면**이고 월포리는 **포항시 청하면**이다. 애초에 9km
떨어져 있어야 한다. 원래 좌표의 위도(36.4171)는 실제로는 남정면보다도 북쪽이라
그것도 맞지 않았다.

### 정답을 어떻게 찾았나

1. **OSM 행정구역 중심** — 부흥리 `36.2725, 129.3687` · 장사리 `36.2849, 129.3632` ·
   구계리 `36.3177, 129.3646`. 리 순서(남→북: 장사·부흥·구계)와 맞는다
2. **고도 API 로 해안선 지도를 그렸다** — 위도 36.270~36.300 을 0.002 간격으로
   훑어 육지→바다 전이 경도를 찾았다
3. **평탄 사구가 하나뿐이었다** — 36.280~36.290 이 고도 2~7m 이고 그 남북은
   전부 산지(54~176m)다. 해변은 여기밖에 없다
4. **장사상륙작전 전승기념관**(OSM `36.2801, 129.3788`)이 사구 남단에 있다.
   장사해변이 거기고, 리서치가 **부흥해변은 장사해변 북쪽**이라 하므로 북단을 골랐다

> **왜 어제 이걸 못 했나.** 어제는 "내륙이다"까지만 보고 가장 가까운 해안으로
> 옮겼다. **행정구역을 확인하지 않았다.** 고도 신호는 "해변인가"만 말하고
> "맞는 해변인가"는 말하지 못한다 — 그게 물치가 1년 반 동안 안 잡힌 이유와
> 같은 구조다.

## 4. 회귀 테스트가 이 도구의 핵심이다

`--fixtures` 가 **틀렸던 좌표 8곳을 넣어 전부 다시 잡히는지** 확인한다.
옛 좌표는 git 이력에서 떴다(`9b21031^` 등).

```

포항 월포      elev      24m  → ✅   해안에서 0.94km 내륙
고성 천진      elev      23m  → ✅   13km 북쪽
물치          overlap  1.32km → ✅   21.5km 남쪽
남애3리        overlap  0.58km → ✅   3.9km 북쪽
동해 대진      elev      27m  → ✅   해안에서 1.06km 내륙
강릉 남애      offshore   0m  → ✅   해상 3.3km
영덕 부흥(2차) overlap  0.85km → ✅   09-27 수정이 24.7km 남쪽으로
```

8/8 통과. **신호를 고치다 하나를 죽이면 여기서 드러난다.**
